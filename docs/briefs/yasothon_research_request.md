# คำขอค้นคว้า: ประวัติศาสตร์ยโสธร

## เรากำลังทำอะไร

เราทำคลิปแนวตั้งความยาว 60 วินาทีสำหรับ Instagram และ TikTok คลิปเป็นโมเดลสามมิติของเมืองบนแผ่นดินสี่เหลี่ยม
ตัวนับปี พ.ศ. วิ่งจากอดีตมาถึงปัจจุบัน เมืองค่อยๆ เกิดขึ้น เติบโต และเปลี่ยนไปตามเหตุการณ์จริง
แต่ละช่วงมีแคปชันสั้นๆ กำกับ ทุกอย่างในคลิปสร้างด้วยโค้ด และคลิปจะเผยแพร่สู่สาธารณะ
จึงต้องการข้อมูลที่ถูกต้องและตรวจสอบแหล่งได้

ขอให้ค้นอย่างกว้างและลึก **ไม่ต้องยึดเส้นเรื่องที่เรามีอยู่** เราอยากได้เรื่องที่คนยโสธรเองอาจยังไม่รู้

## ทำไมเลือกยโสธร

- **บั้งไฟ** เป็นคำแรกในคำขวัญจังหวัด ("เมืองบั้งไฟโก้ แตงโมหวาน หมอนขวานผ้าขิด แหล่งผลิตข้าวหอมมะลิ")
  และคนในชุมชนทำบั้งไฟกันเองทุกปี ภาพเปิดที่เราเสนอคือบั้งไฟยักษ์ที่ถูกมัดเชือกไปแล้วครึ่งลำ มัดต่อจนเสร็จ
  ใส่หาง แล้วตั้งขึ้นบนฮ้าน
- **การจุดบั้งไฟ** เป็นเหตุการณ์ใหญ่และใกล้ในวินาทีที่ 3–9 และเป็นบั้งไฟลำเดียวกับภาพเปิด
- **เมืองที่โตจาก 0 ไป 100:** บ้านสิงห์ท่าริมน้ำชี → ยกเป็นเมืองยศสุนทร (2357?) → ย่านการค้าสิงห์ท่า → อยู่ใต้อุบลฯ →
  แยกเป็นจังหวัด (1 มี.ค. 2515) → ข้าวหอมมะลิ งานบุญบั้งไฟใหญ่ขึ้น → เมืองวันนี้และงานบุญบั้งไฟเดือนพฤษภาคม

ที่เราตรวจแล้วเบื้องต้น (จากผลค้นหา ยังไม่ได้อ่านหน้าเต็ม): รัชกาลที่ 2 ยกบ้านสิงห์ท่าเป็นเมืองยศสุนทร พ.ศ. 2357
ราชวงศ์คำสิงห์เป็นพระสุนทรราชวงศา เจ้าเมืองคนแรก (2357–2366) แต่เว็บจังหวัดเขียนว่าตั้งเมืองในรัชกาลที่ 3 สมัยศึกเจ้าอนุวงศ์
ซึ่งไม่ตรงกัน ประกาศคณะปฏิวัติฉบับที่ 70 (6 ก.พ. 2515) ตั้งจังหวัดยโสธร มีผล 1 มี.ค. 2515
พิพิธภัณฑ์พญาคันคากเป็นอาคารรูปคางคก สูง 19 เมตร งานบุญบั้งไฟ 2569 จัด 8–10 พ.ค. ที่สวนสาธารณะพญาแถน
**ยังหาไม่เจอ:** ปีที่ยศสุนทรกลายเป็นยโสธร ปีที่บุญบั้งไฟยโสธรกลายเป็นงานใหญ่ของจังหวัด ปีที่เริ่มมีบั้งไฟแสน/ล้าน
ปีเปิดพิพิธภัณฑ์พญาคันคาก อายุพระธาตุพระอานนท์

## สิ่งที่ทำให้เรื่องหนึ่ง "ใช้ได้" ในคลิปของเรา

คนดูอยู่ต่อเมื่อ **มีอะไรเกิดขึ้นบนจอ** ไม่ใช่แค่ตัวหนังสือ: คนหรือสัตว์เคลื่อนที่ สิ่งก่อสร้างผุดขึ้น ธรรมชาติเปลี่ยนแผ่นดิน
ยานพาหนะใหม่มาถึง งานเทศกาลที่มีคนมาก

**ภาพแรกสำคัญที่สุด** สถิติจากคลิปที่ผ่านมา: ภาพแรกที่ได้ผลคือ **สัญลักษณ์ของเมืองที่ทำด้วยมือไปแล้วครึ่งหนึ่งในวินาทีแรก
และเปลี่ยนรูปทรงจนเสร็จ** (ไหบ้านเชียงถูกวาดลาย โอ่งมังกรถูกปั้น พลอยถูกเจียระไน เหล็กน้ำพี้ถูกตีเป็นดาบ)
คนแชร์เมื่อเป็นของที่คนในเมืองภูมิใจ ไม่ใช่ของดังระดับประเทศ เหตุการณ์แรกหลังภาพเปิด (วินาทีที่ 3–9) ต้องใหญ่และอยู่ใกล้
และดีที่สุดถ้าเป็นของชิ้นเดียวกับภาพเปิดในมือคนท้องถิ่น

## ขอบเขตที่อยากให้ค้น (ค้นนอกจากนี้ได้เต็มที่)

1. **ก่อนเป็นเมือง:** บ้านสิงห์ท่าตั้งเมื่อไร โดยใคร (สายพระวอ พระตา / เจ้าราชวงศ์เมืองโขง?) ชื่อ "สิงห์ท่า" มาจากไหน
   (ท่าน้ำ? รูปสิงห์?) ตั้งอยู่ริมน้ำชีฝั่งไหน มีหลักฐานโบราณคดีก่อนหน้านั้นในเขตยโสธรไหม (สมัยทวารวดี ขอม ใบเสมา)
2. **ตั้งเมือง:** ปีที่ยกบ้านสิงห์ท่าเป็นเมือง (2357 รัชกาลที่ 2 หรือรัชกาลที่ 3?) ชื่อยศสุนทรได้รับพระราชทานจริงหรือแค่เสนอ
   กลายเป็น "ยโสธร" เมื่อไร เจ้าเมืองสืบต่อกันอย่างไร ศึกเจ้าอนุวงศ์ (2369–2371) เกี่ยวกับยโสธรอย่างไร
   ช่วงปฏิรูปมณฑล ยโสธรเป็นเมือง/อำเภอใต้อุบลฯ ตั้งแต่ปีไหน **แยกพงศาวดาร ตำนาน และหลักฐานร่วมสมัยให้ชัด**
3. **บั้งไฟ:** บุญบั้งไฟของยโสธรมีหลักฐานเก่าสุดเมื่อไร งานกลายเป็นงานประจำจังหวัด/ร่วมกับ ททท. ปีไหน
   บั้งไฟแบบโบราณหน้าตาอย่างไร (กระบอกไม้ไผ่ เชือก/หวายที่มัด หาง ความยาว ฮ้านหรือค้างที่จุด) บั้งไฟเอ้ (ประดับหัวพญานาค)
   เริ่มเมื่อไร บั้งไฟหมื่น แสน ล้าน หนักเท่าไร เริ่มมีเมื่อไร ตำนานพญาคันคากฉบับยโสธร พิพิธภัณฑ์พญาคันคากเปิดปีไหน
   **ไม่ต้องให้สูตรดินปืนหรือวิธีอัดหมื่อ** เราต้องการแค่หน้าตาภายนอกและขั้นตอนที่เห็นได้ (มัด ลาย แห่ ตั้งฮ้าน จุด)
4. **ย่านสิงห์ท่าและการเติบโต:** ย่านการค้าเก่าเกิดเมื่อไร ใครค้า (ลาว จีน เวียดนาม?) ค้าอะไร ทางน้ำชีหรือทางเกวียน
   ตึกแถวเก่าสร้างปีไหน สะพานข้ามน้ำชีแห่งแรกปีไหน ถนนแจ้งสนิท (ทางหลวง 23) มาถึงเมื่อไร **เมืองขยายไปทางไหนในแต่ละช่วง**
5. **สมัยใหม่:** ตั้งจังหวัด 2515 (ราชกิจจานุเบกษา) ข้าวหอมมะลิและเกษตรอินทรีย์ของยโสธรเริ่มเมื่อไร หมอนขวานผ้าขิดบ้านศรีฐาน
   เริ่มเป็นของขึ้นชื่อเมื่อไร พระธาตุพระอานนท์ (วัดมหาธาตุ) สร้างเมื่อไร พระธาตุก่องข้าวน้อย (อายุจากกรมศิลปากร)
6. **ปัจจุบัน:** งานบุญบั้งไฟวันนี้ (วันที่ ขบวนแห่ จำนวนบั้งไฟ ฮ้านจุดอยู่ตรงไหน) คำขวัญจังหวัดแบบคำต่อคำ
   อนุสาวรีย์พระสุนทรราชวงศา อาหารขึ้นชื่อ

**ไม่ต้องค้น:** การเมืองร่วมสมัยและนักการเมืองที่ยังมีบทบาท สูตรหรือวิธีทำดินปืน

## รูปแบบคำตอบที่ขอ

**ส่วนที่ 1: ตารางเหตุการณ์** เรียงตามเวลา

| พ.ศ. | ค.ศ. | เหตุการณ์ | เห็นอะไรบนจอได้ | ระดับความแน่นอน | แหล่งอ้างอิง |
|---|---|---|---|---|---|

ระดับความแน่นอน: **ยืนยัน** (หลายแหล่งอิสระตรงกัน) · **สันนิษฐาน / ตามตำนาน / ตามพงศาวดาร** (ระบุที่มา) · **ขัดแย้ง** (บอกว่าแต่ละแหล่งว่าอย่างไร)

**ส่วนที่ 2: ภาพแรก** เราเสนอบั้งไฟยักษ์ถูกมัด (ดู `yasothon_styleframes.jpg`: A1 บั้งไฟ A2 หมอนขวานผ้าขิด B พญาคันคากยักษ์)
ช่วยบอกว่าบั้งไฟแบบดั้งเดิมของยโสธรหน้าตาอย่างไร (วัสดุ สีของเชือก ลายที่พัน หัว หาง ขนาด) ฮ้านจุดบั้งไฟหน้าตาอย่างไร
หมอนขวานผ้าขิดมีกี่ช่อง สีและลายขิดแบบยโสธร และเสนอทางเลือกอื่นได้ถ้าเห็นว่าดีกว่า

**ส่วนที่ 3: เกร็ดที่คนไม่ค่อยรู้** เรื่องที่ทำให้คนยโสธรอยากคอมเมนต์เติมหรือแชร์ต่อ

**ส่วนที่ 4: ขนาดและพิกัด**
- ความกว้างแม่น้ำชีช่วงตัวเมือง ขนาดย่านสิงห์ท่าเก่า ความสูงฮ้านบั้งไฟที่สวนพญาแถน ความยาวบั้งไฟแสน/ล้าน
  ขนาดพิพิธภัณฑ์พญาคันคาก ความสูงพระธาตุพระอานนท์
- lat, lon ของ: วัดสิงห์ท่า ท่าน้ำเก่าที่บ้านสิงห์ท่า ย่านตึกเก่า วัดมหาธาตุ อนุสาวรีย์พระสุนทรราชวงศา สวนสาธารณะพญาแถนและฮ้านจุดบั้งไฟ
  พิพิธภัณฑ์พญาคันคาก สะพานข้ามน้ำชี ศาลากลางเก่าและใหม่ พระธาตุก่องข้าวน้อย บ้านศรีฐาน

**ส่วนที่ 5: ข้อควรระวัง** ปีตั้งเมือง (2357 กับรัชกาลที่ 3) ชื่อยศสุนทร เรื่องเล่าที่แพร่หลายแต่ไม่มีหลักฐาน
อุบัติเหตุบั้งไฟที่ไม่ควรเอามาเล่น

**ส่วนที่ 6: สถานที่ในเรื่อง (story places)** บรรทัดละหนึ่งแห่ง: ชื่อ / ยุค / สำคัญกับเรื่องอย่างไร / lat, lon (หรือ "ไม่พบ") / แหล่งอ้างอิง
อย่างน้อยหนึ่งแห่งต่อทุกยุคของเรื่อง สถานที่ที่ไม่มีใน OpenStreetMap คือสิ่งที่ต้องการมากที่สุด
โดยเฉพาะ: **จุดตั้งบ้านสิงห์ท่าและท่าน้ำ** **จุดจุดบั้งไฟแบบดั้งเดิม (ก่อนมีสวนพญาแถน)** **ย่านการค้าเก่า**

## ข้อกำหนด

- ให้ความสำคัญกับแหล่งภาษาไทย เช่น กรมศิลปากร ศิลปวัฒนธรรม ThaiJO เว็บจังหวัดและเทศบาลเมืองยโสธร
  มหาวิทยาลัยราชภัฏ/มหาวิทยาลัยอุบลราชธานี The Isaan Record วิกิพีเดียภาษาอังกฤษมักผิดเรื่องปีของประวัติศาสตร์ท้องถิ่นไทย
- ทุกปีที่ระบุต้องมีลิงก์หรือชื่อเอกสารอ้างอิง
- ถ้าหาไม่เจอ ให้เขียนว่า "ไม่พบ" แทนการเดา
- แยกให้ชัดว่าเรื่องไหนเป็นตำนาน เรื่องไหนเป็นพงศาวดาร และเรื่องไหนเป็นหลักฐานร่วมสมัย
