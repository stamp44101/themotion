# ผลการค้นคว้า: ประวัติศาสตร์พะเยา (ภูกามยาว เมืองริมกว๊าน)

ตอบตามรูปแบบใน `docs/briefs/yasothon_research_request.md` (6 ส่วน) สำหรับคลิปไทม์แลปส์ 60 วินาทีของตัวเมืองพะเยา
ค้นเมื่อ 15 พ.ย. 2569 (2026) โดย [cloud] คนเดียว (ไม่มีรอบ [gemini] / [local])

**วิธีค้นและข้อจำกัด (อ่านก่อน):**
- อ่านเต็มหน้าได้เฉพาะ th.wikipedia / en.wikipedia (wikitext ผ่าน API; โดนจำกัดอัตราบ่อย ได้มา: จังหวัดพะเยา, อำเภอเมืองพะเยา,
  วัดศรีโคมคำ, กว๊านพะเยา, พญางำเมือง, แคว้นพะเยา, en: Phayao, Phayao province, Kwan Phayao) ส่วนแหล่งอื่น (ศิลปวัฒนธรรม,
  ONEP, ประชาชาติ, gotoknow, TrueID, เว็บท่องเที่ยว, ThaiJO) เห็นผ่าน **ผลค้นหาและข้อความย่อ** เท่านั้น ติดป้าย **(ข้อความย่อ)**
- พิกัดจาก OSM (Overpass mirror maps.mail.ru) และ Nominatim; ภาพถ่ายดาวเทียม Esri World_Imagery (`phayao_onep/`)

- ศักราชในตำนาน (พื้นเมืองพะเยา, ชินกาลมาลีปกรณ์) ใช้ได้เป็นช่วงสมัย ไม่ใช้เป็นปีที่ตัวนับหยุด

**ข้อเสนอ: A1** — ตราจังหวัดที่คนพะเยาเรียกว่าของตัวเอง (ทางเดียวที่แชร์ขึ้นตาม §15–§20), ครึ่งทำด้วยมือแบบโถ/อัญมณี/ดาบ
และรูปทรงเปลี่ยนชัด (พระไม่มีเศียร → มีเศียร) ใช้ A2 (วัดจม) เป็นบีต 2482 กลางเรื่อง และ B (ปลาบึก) เป็นลูกเล่นในฉากสถานีประมง

**ลำดับภาพที่เสนอ (0–9 วินาที):** เฟรม 0 พระองค์ใหญ่ขนาดตำนานบนแหลมริมหนองเอี้ยง อกเป็นอิฐ นั่งร้านไผ่ คนขนอิฐ (เสียงแรก: ค้อนเคาะอิฐ, เสียงปูน)
→ 0–3 วิ เศียรขึ้น ฉาบขาว ลงทอง → 3–9 วิ (ใกล้ มีคน) ย้อนเวลาเร่งไปสามกษัตริย์ริมน้ำอิง (ราว 1830, ไม่ถือปี) หรือ
ขบวนคนจากลำปางเข้าเวียงร้าง 2386 (ถือปีได้) — ให้ตัดสินในสตอรีไลน์

## ส่วนที่ 3: เกร็ดที่คนไม่ค่อยรู้

1. **ที่สามกษัตริย์ดื่มน้ำสาบานจมอยู่ใต้กว๊าน** — wiki ว่าทำสัตย์ "ณ บริเวณน้ำแม่อิง ซึ่งปัจจุบันอยู่บริเวณกว๊านพะเยา"
2. **กว๊านพะเยาไม่ใช่ทะเลสาบธรรมชาติ** — เป็นทุ่งนาและหนองน้ำ (หนองเอี้ยง) ที่น้ำอิงไหลผ่าน จนกรมประมงทำประตูกั้นน้ำ (2482) น้ำจึงท่วมบ้าน ทุ่ง และวัด
   ทั้งชุมชน; หน้าแล้ง 2563 ซากวัดโผล่ขึ้นมาให้เห็น
3. **วัดติโลกอารามจมอยู่ใต้น้ำ ~500 ปีหลังสร้าง** (สร้าง 2019–2029 จมหลัง 2482) ทุกวันนี้คนพายเรือไปเวียนเทียนกลางน้ำ
4. **พระเจ้าตนหลวงใช้เวลาสร้าง ~33 ปี** (2034–2067) และวันฉลองเสร็จคือเพ็ญเดือนแปด → ชื่อประเพณี "แปดเป็ง"
5. **พะเยาเคยร้าง** ช่วงสงครามพม่า แล้วรัชกาลที่ 3 ตั้งเมืองขึ้นใหม่ (2386) ด้วยคนจากลำปาง
6. **พะเยาเป็นจังหวัดที่ 72** แยกจากเชียงรายเมื่อ 2520 (ก่อนหน้านั้นเป็นแค่อำเภอของเชียงรายราว 70 ปี)
7. **พญางำเมือง** = "บังเมือง" ฝนไม่รั่ว แดดไม่ร้อนเมื่อเสด็จ (ตำนาน); เรื่อง "แกงหวานบ้านแตก" ทำให้เสียเมืองปัว (ตำนาน)

## ส่วนที่ 4: เมืองโตอย่างไร (สำหรับฉาก grow)
- **ก่อน 2386:** เวียงพะเยา (คูดินบนแหลมริมหนอง ~1.0 × 1.4 กม.) ร้าง ป่าคลุม; วัดศรีโคมคำอยู่นอกเวียงทางเหนือริมหนอง
- **2386–2480:** เมืองฟื้นในเวียง เรือนไม้ วัดในเวียง (ศรีอุโมงค์คำ, ราชคฤห์) ถนนพหลโยธินตัดผ่านตะวันออกของเวียง (ปีที่ตัดยังไม่ตรวจ)
- **2482–2484:** ประตูน้ำปิด กว๊านเกิด เวียงกลายเป็นแหลมยื่นลงน้ำ (ฝั่งตะวันตกและใต้เป็นน้ำ)
- **2520 →:** เมืองหลวงจังหวัด โตขึ้นเหนือ (บ้านต๋อม ศาลากลาง โรงพยาบาล) และตะวันออกตามถนนพหลโยธินและทางไปเชียงคำ; ริมกว๊านเป็นสวนสาธารณะ
- **2553 →:** มหาวิทยาลัยพะเยา 15 กม. ใต้ (นอกแผ่นดิน)

## ส่วนที่ 5: ข้อควรระวัง
1. **ห้ามถือบนตัวนับ:** 1638, 1805/1819, ราว 1830, 1839, 1877–1879 (ตำนาน/ขัดแย้ง); 2034 และ 2067 (ประวัติวัด แหล่งชั้นต้นไม่พบ) — ใช้เป็นคำบรรยายย่อยไม่มีปีได้
2. **ถือได้:** 2386 (ตั้งเมืองใหม่), 2482 (ประตูน้ำ; บอกเจ้าของว่ามีแหล่งเขียน 2484 ด้วย), 2520 (ตั้งจังหวัด), 2466 (ครูบาศรีวิชัย, wiki แหล่งเดียว)
3. ชื่อ: ใช้ "พญางำเมือง" (ตามป้ายอนุสาวรีย์และคำขวัญว่า "พ่อขุนงำเมือง") ; "พ่อขุนรามคำแหง" ในคำบรรยายถ้าพูดถึงสามกษัตริย์
4. **อุโบสถกลางน้ำ (2528) ไม่ใช่วัดติโลกอาราม** — อย่าสลับ
5. ห้ามแสดง: ไม่มีเหตุการณ์อ่อนไหวที่เจอในรอบนี้
