# คำขอค้นคว้า: ประวัติศาสตร์สกลนคร

## เรากำลังทำอะไร

เราทำคลิปแนวตั้งความยาว 60 วินาทีสำหรับ Instagram และ TikTok คลิปเป็นโมเดลสามมิติของเมืองบนแผ่นดินสี่เหลี่ยม
ตัวนับปี พ.ศ. วิ่งจากอดีตมาถึงปัจจุบัน เมืองค่อยๆ เกิดขึ้น เติบโต และเปลี่ยนไปตามเหตุการณ์จริง
แต่ละช่วงมีแคปชันสั้นๆ กำกับ ทุกอย่างในคลิปสร้างด้วยโค้ด และคลิปจะเผยแพร่สู่สาธารณะ
จึงต้องการข้อมูลที่ถูกต้องและตรวจสอบแหล่งได้

ขอให้ค้นอย่างกว้างและลึก **ไม่ต้องยึดเส้นเรื่องที่เรามีอยู่** เราอยากได้เรื่องที่คนสกลเองอาจยังไม่รู้

## ทำไมเลือกสกลนคร

- **ผ้าคราม** เป็นของที่คนสกลเป็นเจ้าของ (ผ้าประจำจังหวัด และขึ้นทะเบียน GI) ภาพเปิดที่เราเลือกคือผ้าผืนยักษ์ถูกย้อมครามในวินาทีแรก
- **หนองหาร** กับตำนานเมืองล่ม เป็นเหตุการณ์ใหญ่ที่เห็นบนจอได้
- **เมืองที่โตจาก 0 ไป 100:** ปราสาทขอม → พระธาตุเชิงชุม → หนองหารหลวง → สกลทวาปี → สกลนคร 2381 → เสรีไทยในเทือกเขาภูพาน → เมืองวันนี้
  → งานแห่ปราสาทผึ้ง

ที่เราตรวจแล้วเบื้องต้น: เปลี่ยนชื่อเป็นเมืองสกลนคร 17 ส.ค. 2381 (เอกสาร GI ของกรมทรัพย์สินทางปัญญา และเดลินิวส์) ผู้ว่าราชการคนแรก
พระยาประจันตประเทศธานี เปลี่ยนเป็นจังหวัด 2476 พระธาตุเชิงชุมเดิมเป็นปราสาทแบบขอม (ราวพุทธศตวรรษที่ 16) แล้วสร้างเจดีย์ล้านช้างครอบ
งานแห่ปราสาทผึ้ง 1–7 ต.ค. 2568 และ 20–26 ต.ค. 2569 **ยังหาไม่เจอ:** ปีที่เปลี่ยนชื่อเป็นสกลทวาปี (2370?) และปีที่ผ้าครามขึ้นทะเบียน GI

## สิ่งที่ทำให้เรื่องหนึ่ง "ใช้ได้" ในคลิปของเรา

คนดูอยู่ต่อเมื่อ **มีอะไรเกิดขึ้นบนจอ** ไม่ใช่แค่ตัวหนังสือ: คนหรือสัตว์เคลื่อนที่ สิ่งก่อสร้างผุดขึ้น ธรรมชาติเปลี่ยนแผ่นดิน
(น้ำท่วม ทะเลสาบเกิด) ยานพาหนะใหม่มาถึง งานเทศกาลที่มีคนมาก

**ภาพแรกสำคัญที่สุด** สถิติจากคลิปที่ผ่านมา: ภาพแรกที่ได้ผลคือ **สัญลักษณ์ของเมืองที่เปลี่ยนรูปและเต็มจอในวินาทีแรก**
(ไหบ้านเชียงถูกวาดลาย โอ่งมังกรถูกปั้น) และคนแชร์เมื่อเป็นของที่คนในเมืองภูมิใจ ไม่ใช่ของดังระดับประเทศ
เหตุการณ์แรกหลังภาพเปิด (วินาทีที่ 3–9) ต้องใหญ่และอยู่ใกล้

## ขอบเขตที่อยากให้ค้น (ค้นนอกจากนี้ได้เต็มที่)

1. **ก่อนประวัติศาสตร์ถึงขอม:** แหล่งโบราณคดีรอบหนองหาร (ยุคบ้านเชียง?) ปราสาทขอมในสกล (พระธาตุเชิงชุม พระธาตุนารายณ์เจงเวง
   พระธาตุดุม) อายุและหลักฐาน จารึก
2. **ตำนานหนองหาร:** ทุกฉบับ (พญาขอม/พังคี กระรอกเผือก ผาแดงนางไอ่ เมืองเอกชะทีตา?) ฉบับไหนผูกกับหนองหารสกล ฉบับไหนผูกกับ
   หนองหารกุมภวาปีของอุดร ตำนานอุรังคธาตุกับพระเจ้าสุวรรณภิงคาร **แยกตำนานกับประวัติศาสตร์ให้ชัด**
3. **ล้านช้างถึงรัตนโกสินทร์:** เมืองหนองหารหลวง การตั้งเมืองสกลทวาปี (ปีไหน ใครตั้ง ย้ายคนมาจากไหน) การตั้งเมืองสกลนคร 2381 ราชวงศ์(คำ)
   การอพยพคนกลุ่มต่างๆ (ภูไท ญ้อ โย้ย กะเลิง โส้ ลาว) เข้าสกล ตัวเมืองเดิมอยู่ตรงไหนริมหนองหาร
4. **เสรีไทยและภูพาน:** เตียง ศิริขันธ์ ค่ายในเทือกเขาภูพาน (ถ้ำเสรีไทย) ปี การลงสนามบินลับ ระวังรายละเอียดที่แพร่หลายแต่ไม่มีหลักฐาน
5. **การเติบโต:** ลำดับสิ่งที่เกิดขึ้นในตัวเมืองพร้อมปี: ศาลากลาง ตลาด ถนนสายหลัก สนามบิน มหาวิทยาลัย (ราชภัฏ เกษตรศาสตร์ฉลิมพระเกียรติ)
   พระตำหนักภูพานราชนิเวศน์ ฯลฯ **เมืองขยายไปทางไหนในแต่ละช่วง**
6. **ผ้าครามและงานปราสาทผึ้ง:** ผ้าครามมาจากไหน ใครทอ ปีขึ้นทะเบียน GI เลขทะเบียน; งานแห่ปราสาทผึ้งเริ่มปีไหน หน้าตาปราสาทผึ้ง
   (ผึ้งดอก ผึ้งพิมพ์) ขบวนแห่ออกจากที่ไหนไปที่ไหน คำขวัญจังหวัดแบบคำต่อคำ อาหารขึ้นชื่อ

**ไม่ต้องค้น:** การเมืองร่วมสมัยและนักการเมืองที่ยังมีบทบาท

## รูปแบบคำตอบที่ขอ

**ส่วนที่ 1: ตารางเหตุการณ์** เรียงตามเวลา

| พ.ศ. | ค.ศ. | เหตุการณ์ | เห็นอะไรบนจอได้ | ระดับความแน่นอน | แหล่งอ้างอิง |
|---|---|---|---|---|---|

ระดับความแน่นอน: **ยืนยัน** (หลายแหล่งอิสระตรงกัน) · **สันนิษฐาน / ตามตำนาน** (ระบุที่มา) · **ขัดแย้ง** (บอกว่าแต่ละแหล่งว่าอย่างไร)

**ส่วนที่ 2: ภาพแรก** เราเลือกผ้าครามแล้ว (ดู `sakonnakhon_styleframes.jpg`) ช่วยบอกว่าลายมัดหมี่แบบไหนที่คนสกลจำได้ที่สุด สีและวิธีย้อมจริง
(หม้อนิล การจุ่มกี่ครั้ง ผ้าตอนขึ้นจากหม้อเป็นสีเขียวก่อนกลายเป็นน้ำเงินหรือไม่) และเสนอทางเลือกอื่นได้ถ้าเห็นว่าดีกว่า

**ส่วนที่ 3: เกร็ดที่คนไม่ค่อยรู้** เรื่องที่ทำให้คนสกลอยากคอมเมนต์เติมหรือแชร์ต่อ

**ส่วนที่ 4: ขนาดและพิกัด**
- ขนาดหนองหาร (ตร.กม. ยาว กว้าง) เกาะในหนองหาร (ดอนสวรรค์ ดอนโพธิ์?) ความสูงพระธาตุเชิงชุม ขนาดปราสาทผึ้งในขบวน
- lat, lon ของ: พระธาตุเชิงชุม พระธาตุนารายณ์เจงเวง พระธาตุดุม ศาลากลางเก่าและใหม่ ศาลหลักเมือง ตลาดเก่า สนามบิน
  พระตำหนักภูพานราชนิเวศน์ ถ้ำเสรีไทย จุดเริ่มและจบขบวนแห่ปราสาทผึ้ง

**ส่วนที่ 5: ข้อควรระวัง** ตำนานที่หลายจังหวัดอ้าง ปีที่เว็บต่างๆ มักอ้างผิด (สกลทวาปี 2370? ตั้งเมือง 2381) เรื่องเสรีไทยที่แพร่หลายแต่ไม่มีหลักฐาน

**ส่วนที่ 6: สถานที่ในเรื่อง (story places)** บรรทัดละหนึ่งแห่ง: ชื่อ / ยุค / สำคัญกับเรื่องอย่างไร / lat, lon (หรือ "ไม่พบ") / แหล่งอ้างอิง
อย่างน้อยหนึ่งแห่งต่อทุกยุคของเรื่อง สถานที่ที่ไม่มีใน OpenStreetMap คือสิ่งที่ต้องการมากที่สุด
โดยเฉพาะ: **ตัวเมืองเดิมริมหนองหาร** **แนวคูเมืองหรือกำแพง (ถ้ามี)** **ที่ตั้งเมืองสกลทวาปี**

## ข้อกำหนด

- ให้ความสำคัญกับแหล่งภาษาไทย เช่น กรมศิลปากร ศิลปวัฒนธรรม ThaiJO เว็บจังหวัดและเทศบาลนครสกลนคร มหาวิทยาลัยราชภัฏสกลนคร
  วิกิพีเดียภาษาอังกฤษมักผิดเรื่องปีของประวัติศาสตร์ท้องถิ่นไทย
- ทุกปีที่ระบุต้องมีลิงก์หรือชื่อเอกสารอ้างอิง
- ถ้าหาไม่เจอ ให้เขียนว่า "ไม่พบ" แทนการเดา
- แยกให้ชัดว่าเรื่องไหนเป็นตำนาน และเรื่องไหนเป็นหลักฐานทางประวัติศาสตร์
