# ผลการค้นคว้า: ประวัติศาสตร์หนองคาย (เมืองริมโขง บ้านไผ่)

รูปแบบเดียวกับ `docs/briefs/kalasin_research.md` (6 ส่วน) สำหรับคลิปไทม์แลปส์ 60 วินาทีของตัวเมืองหนองคาย
ค้นเมื่อ 18 พ.ย. 2569 (2026) โดย cloud คนเดียว (ไม่มีรอบ [gemini] / [local])

**วิธีค้นและข้อจำกัด (อ่านก่อน):**
- อ่านเต็มหน้าได้เฉพาะ th.wikipedia (wikitext ผ่าน API): อนุสาวรีย์ปราบฮ่อ, วัดโพธิ์ชัย (จังหวัดหนองคาย), สถานีรถไฟหนองคาย,
  ศาลาแก้วกู่, บั้งไฟพญานาค, อำเภอเมืองหนองคาย ส่วนแหล่งอื่น (ศิลปวัฒนธรรม, แนวหน้า, ประชาชาติ, ไทยรัฐ, สถานทูตออสเตรเลีย,
  สำนักข่าวลาว KPL, Bangkok Post) เห็นผ่าน **ผลค้นหาและข้อความย่อ** เท่านั้น ติดป้าย (ข้อความย่อ)
- th/en.wikipedia API ติด rate limit (หลาย session ใช้ IP เดียวกัน) หน้า "จังหวัดหนองคาย" และ "หลวงพ่อพระใส" อ่านไม่ได้
- พิกัดจาก OSM (Overpass mirror) และ nominatim; แนวฝั่งแม่น้ำโขงลากจากภาพ Esri World Imagery (OSM riverbank ใหญ่เกิน mirror หมดเวลา)
- **ปีของไทยก่อน พ.ศ. 2484 นับปีใหม่ 1 เม.ย.** เดือน ม.ค.–มี.ค. ในเอกสารเก่าเป็นปี พ.ศ. ที่น้อยกว่าการนับปัจจุบัน 1 ปี
  กระทบการยกวัดโพธิ์ชัย (21 ก.พ. 2382 ในเอกสาร = ค.ศ. 1840 ซึ่งเป็น 2383 ตามการนับปัจจุบัน; สุริยุปราคา 4 มี.ค. 1840 ยืนยันปี ค.ศ.)

### หน้าตาจริงที่หาได้
- เรือยาวอีสาน/ลาว: เรือขุดจากซุงทั้งต้น หัวเรือเชิดสูงแกะเป็นหัวพญานาค ทาสีทองแดง/เขียว ผูกผ้าแพรสีที่หัวเรือ ฝีพายนั่งเป็นคู่
- เรือคำหยาดเก็บที่วัดสุธรรมนิมิต บ้านกวนวันใหญ่ (ข้อความย่อ) ความยาวไม่พบ

## ส่วนที่ 3: เกร็ดที่คนไม่ค่อยรู้
- พระธาตุกลางน้ำเคยตั้งบนฝั่ง ตลิ่งพังจนองค์พระธาตุล้มลงกลางโขงในปี 2390 หน้าแล้งยังเห็นฐานโผล่
- พระใสไม่ได้ตั้งใจให้อยู่หนองคาย: ปี 2399 จะอัญเชิญไปกรุงเทพฯ พร้อมพระเสริม แต่เกวียนไปไม่ได้จนหัก (ตำนาน)
- พระสุก องค์พี่ จมลงในแม่น้ำโขงระหว่างทาง ที่นั่นเรียก "เวินพระสุก" (wiki)
- อนุสาวรีย์ปราบฮ่อจารึก 4 ภาษา (ไทย จีน ลาว อังกฤษ)
- "บั้งไฟพญานาค" ก่อน 2529 ชาวบ้านเรียก "บั้งไฟผี"
- สะพานมิตรภาพแห่งแรกข้ามโขง ออสเตรเลียออกทุน; รางรถไฟวางอยู่กลางสะพาน รถต้องหยุดเมื่อรถไฟผ่าน

## ส่วนที่ 4: ขนาดและพิกัด
### ขนาด
- แม่น้ำโขงหน้าเมือง กว้าง ~550–650 ม. (วัดจากภาพ Esri); ไหลจากตะวันตกเฉียงใต้ไปตะวันออกเฉียงเหนือ เมืองอยู่ฝั่งใต้ (ไทย) ฝั่งเหนือคือเวียงจันทน์ (ท่าเดื่อ)
- สะพานมิตรภาพ ยาว 1,170 ม. (ถนน 2 ช่อง 3.5 ม., ทางเท้า, รางมิเตอร์เกจกลางสะพาน)
- ตัวเมืองเก่าเป็นแถบยาวริมโขง ~3 กม. × ~0.6 กม. (ท่าเสด็จ–วัดโพธิ์ชัย–วัดหายโศก)
- อนุสาวรีย์ปราบฮ่อองค์ใหม่สูง 10.10 ม. ฐาน 4 ม.
- ศาลาแก้วกู่ 42 ไร่ รูปปั้นสูงสุด ~25 ม.

## ส่วนที่ 5: ข้อควรระวัง
1. **ปีตั้งเมือง 2370** มาจากการนับของจังหวัด (งานฉลองเมือง) ไม่ได้เห็นเอกสารต้นฉบับ แจ้งเจ้าของว่าเป็นปีตามที่จังหวัดนับ
2. **ศาลาแก้วกู่** ปีเริ่มสร้างขัดแย้ง (2513/2519/2521): ไม่ขึ้นปีบนจอ
3. **พระใส 2399** เป็นตำนาน + ปีจากแหล่งเดียว: ไม่ถือปี ใช้คำว่า "ตำนาน" ไม่ใส่ปี
4. **ศึกเจ้าอนุวงศ์** เป็นเรื่องอ่อนไหวกับคนลาว ไม่ทำเป็นฉากรบ; ใช้เป็นบริบทในซับเท่านั้น
5. **ศึกฮ่อ** แสดงเป็นทัพรวมพลและยกข้ามโขง ไม่แสดงความรุนแรง (storyline §3.6a)
6. ไม่แสดง: น้ำท่วมหนองคาย 2551/2560/2567 (ในความทรงจำ มีคนเดือดร้อน) และเรื่องคนตายจากบั้งไฟ/เรือล่ม
7. พระพุทธรูป (พระใส พระเสริม) ไม่ทำขนาดยักษ์หรือเป็นของเล่น; ในฉากเกวียนวาดเป็นองค์สีทองเล็กใต้ฉัตร
