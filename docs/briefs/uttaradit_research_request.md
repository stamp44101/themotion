# คำขอค้นคว้า: ประวัติศาสตร์อุตรดิตถ์

## เรากำลังทำอะไร

เราทำคลิปแนวตั้งความยาว 60 วินาทีสำหรับ Instagram และ TikTok คลิปเป็นโมเดลสามมิติของเมืองบนแผ่นดินสี่เหลี่ยม
ตัวนับปี พ.ศ. วิ่งจากอดีตมาถึงปัจจุบัน เมืองค่อยๆ เกิดขึ้น เติบโต และเปลี่ยนไปตามเหตุการณ์จริง
แต่ละช่วงมีแคปชันสั้นๆ กำกับ ทุกอย่างในคลิปสร้างด้วยโค้ด และคลิปจะเผยแพร่สู่สาธารณะ
จึงต้องการข้อมูลที่ถูกต้องและตรวจสอบแหล่งได้

ขอให้ค้นอย่างกว้างและลึก **ไม่ต้องยึดเส้นเรื่องที่เรามีอยู่** เราอยากได้เรื่องที่คนอุตรดิตถ์เองอาจยังไม่รู้

## ทำไมเลือกอุตรดิตถ์

- **เหล็กน้ำพี้** เป็นของที่คนอุตรดิตถ์เป็นเจ้าของ ภาพเปิดที่เราเสนอคือแท่งเหล็กร้อนแดงบนทั่ง ถูกตีไปแล้วครึ่งหนึ่ง
  ค้อนตีต่อจนกลายเป็นใบดาบในสองวินาทีแรก
- **พระยาพิชัยดาบหัก ศึกเมืองพิชัย 2316** เป็นเหตุการณ์ใหญ่และใกล้ที่เห็นบนจอได้ และเป็นดาบเล่มเดียวกับภาพเปิด
- **เมืองที่โตจาก 0 ไป 100:** บ่อเหล็กน้ำพี้และเมืองพิชัย → ศึก 2316 → ท่าเรือบางโพท่าอิฐริมแม่น้ำน่าน → รถไฟสายเหนือ →
  ย้ายศาลากลางมาอุตรดิตถ์ → เขื่อนสิริกิติ์ → เมืองวันนี้และงานพระยาพิชัยดาบหักทุกเดือนมกราคม

ที่เราตรวจแล้วเบื้องต้น: พม่าตีเมืองพิชัยครั้งที่สองปี 2316 ไม่สำเร็จ (ศิลปวัฒนธรรม) จังหวัดถือวันที่ 7 มกราคม 2316
งานรำลึกปี 2569 เป็นครั้งที่ 59 อาจารย์นิธิ เอียวศรีวงศ์ ตั้งข้อสงสัยเรื่องราชทินนาม (พิชัยอาสา / พิชัยราชา)
ท้องตราปีมะเมีย 2317 พระราชทานเครื่องแต่งกายให้พระยาพิชัยเป็นแม่ทัพไปเชียงใหม่ บ่อพระแสงและบ่อพระขรรค์ที่บ้านน้ำพี้
**ยังหาไม่เจอ:** ปีย้ายศาลากลางจากพิชัยมาบางโพท่าอิฐและปีที่ได้ชื่ออุตรดิตถ์ (2458?) ปีรถไฟถึงอุตรดิตถ์ ปีเริ่มถลุงเหล็กน้ำพี้

## สิ่งที่ทำให้เรื่องหนึ่ง "ใช้ได้" ในคลิปของเรา

คนดูอยู่ต่อเมื่อ **มีอะไรเกิดขึ้นบนจอ** ไม่ใช่แค่ตัวหนังสือ: คนหรือสัตว์เคลื่อนที่ สิ่งก่อสร้างผุดขึ้น ธรรมชาติเปลี่ยนแผ่นดิน
ยานพาหนะใหม่มาถึง งานเทศกาลที่มีคนมาก

**ภาพแรกสำคัญที่สุด** สถิติจากคลิปที่ผ่านมา: ภาพแรกที่ได้ผลคือ **สัญลักษณ์ของเมืองที่ทำด้วยมือไปแล้วครึ่งหนึ่งในวินาทีแรก
และเปลี่ยนรูปทรงจนเสร็จ** (ไหบ้านเชียงถูกวาดลาย โอ่งมังกรถูกปั้น พลอยถูกเจียระไน) คนแชร์เมื่อเป็นของที่คนในเมืองภูมิใจ
ไม่ใช่ของดังระดับประเทศ เหตุการณ์แรกหลังภาพเปิด (วินาทีที่ 3–9) ต้องใหญ่และอยู่ใกล้

## ขอบเขตที่อยากให้ค้น (ค้นนอกจากนี้ได้เต็มที่)

1. **เมืองพิชัยและเมืองเก่า:** อายุเมืองพิชัย (ผลขุดค้นของกรมศิลปากร) ผังเมือง กำแพงดินหรืออิฐ คูเมือง ประตู
   ตั้งริมแม่น้ำน่านฝั่งไหน เมืองทุ่งยั้ง เมืองลับแล วัดพระแท่นศิลาอาสน์ เกี่ยวกับเรื่องนี้อย่างไร
2. **พระยาพิชัยดาบหัก:** ประวัติ (จ้อย / ทองดี ฟันขาว?) ศึก 2316 ตามพงศาวดารแต่ละฉบับ พม่ามาทางไหน รบที่ไหน
   (นอกกำแพง? ที่วัดไหน?) ดาบหักข้างไหน ดาบเป็นดาบตรงหรือดาบโค้ง วันที่ 7 มกราคม 2316 มาจากไหน และตรงกับ ค.ศ. อะไร
   (ปีใหม่ไทยสมัยนั้นเริ่มเดือนเมษายน) **แยกพงศาวดาร ตำนาน และหลักฐานร่วมสมัยให้ชัด**
3. **เหล็กน้ำพี้:** บ่อเหล็กอยู่ตรงไหน ขุดมาตั้งแต่เมื่อไร มีหลักฐานว่าใช้ทำดาบหลวงหรือพระแสงองค์ไหน การถลุงแบบโบราณ
   (เตาดิน สูบลม) และการตีดาบที่บ้านน้ำพี้วันนี้หน้าตาเป็นอย่างไร ดาบพระยาพิชัยทำจากเหล็กน้ำพี้จริงไหม หรือเป็นเรื่องเล่า
4. **บางโพท่าอิฐและการเติบโต:** ท่าอิฐเป็นท่าเรือการค้าเมื่อไร ค้าอะไร (ไม้สัก ของป่า เรือจากหลวงพระบาง/น่าน?)
   รถไฟสายเหนือถึงพิชัย อุตรดิตถ์ และศิลาอาสน์ปีไหน (แต่ละสถานี) ย้ายศาลากลางจากพิชัยมาบางโพท่าอิฐปีไหน
   ได้ชื่อ "อุตรดิตถ์" ปีไหน ใครตั้ง ไฟไหม้ตลาดใหญ่ (ถ้ามี) สะพาน ถนน **เมืองขยายไปทางไหนในแต่ละช่วง**
5. **เขื่อนสิริกิติ์และสมัยใหม่:** เริ่มสร้าง ปิดเขื่อน เปิดใช้ ปีไหน ความสูง ความยาว อ่างเก็บน้ำท่วมอะไรไป
   สงครามบ้านร่มเกล้า 2530–31 (ถ้าจะใช้ ต้องระวัง) ลางสาดลับแล ทุเรียนหลงลับแล
6. **ปัจจุบัน:** งานพระยาพิชัยดาบหัก (วันที่ หน้าตาของงาน ขบวน การแสดงฟันดาบ) อนุสาวรีย์หน้าศาลากลางและที่พิชัย
   คำขวัญจังหวัดแบบคำต่อคำ อาหารขึ้นชื่อ

**ไม่ต้องค้น:** การเมืองร่วมสมัยและนักการเมืองที่ยังมีบทบาท

## รูปแบบคำตอบที่ขอ

**ส่วนที่ 1: ตารางเหตุการณ์** เรียงตามเวลา

| พ.ศ. | ค.ศ. | เหตุการณ์ | เห็นอะไรบนจอได้ | ระดับความแน่นอน | แหล่งอ้างอิง |
|---|---|---|---|---|---|

ระดับความแน่นอน: **ยืนยัน** (หลายแหล่งอิสระตรงกัน) · **สันนิษฐาน / ตามตำนาน / ตามพงศาวดาร** (ระบุที่มา) · **ขัดแย้ง** (บอกว่าแต่ละแหล่งว่าอย่างไร)

**ส่วนที่ 2: ภาพแรก** เราเสนอการตีเหล็กน้ำพี้เป็นดาบ (ดู `uttaradit_styleframes.jpg`: A1 ดาบเล่มเดียว A2 ดาบสองมือ
B ดาบหักหน้ากำแพงพิชัย) ช่วยบอกว่าเหล็กน้ำพี้ก่อนตีหน้าตาอย่างไร (สี ผิว) เตาและทั่งของช่างบ้านน้ำพี้หน้าตาอย่างไร
ดาบพระยาพิชัยรูปทรงแบบไหน และเสนอทางเลือกอื่นได้ถ้าเห็นว่าดีกว่า

**ส่วนที่ 3: เกร็ดที่คนไม่ค่อยรู้** เรื่องที่ทำให้คนอุตรดิตถ์อยากคอมเมนต์เติมหรือแชร์ต่อ

**ส่วนที่ 4: ขนาดและพิกัด**
- ความกว้างแม่น้ำน่านช่วงตัวเมืองอุตรดิตถ์และช่วงพิชัย ขนาดเมืองพิชัยเก่า ระยะจากพิชัยถึงตัวเมืองอุตรดิตถ์
  ขนาดเขื่อนสิริกิติ์ ความสูงอนุสาวรีย์
- lat, lon ของ: เมืองพิชัยเก่า (กำแพง ประตู) วัดราชบูรณะ (พิชัย) อนุสาวรีย์ที่พิชัยและหน้าศาลากลาง บ่อเหล็กน้ำพี้
  ท่าอิฐ สถานีอุตรดิตถ์ สถานีศิลาอาสน์ วัดพระแท่นศิลาอาสน์ เขื่อนสิริกิติ์ ศาลากลางเก่าและใหม่

**ส่วนที่ 5: ข้อควรระวัง** วันที่ 7 มกราคม 2316 กับปี ค.ศ. ตัวตนของพระยาพิชัยดาบหัก (ข้อโต้แย้งของอาจารย์นิธิ)
ปีย้ายเมืองที่เว็บอ้างไม่ตรงกัน เรื่องเล่าที่แพร่หลายแต่ไม่มีหลักฐาน

**ส่วนที่ 6: สถานที่ในเรื่อง (story places)** บรรทัดละหนึ่งแห่ง: ชื่อ / ยุค / สำคัญกับเรื่องอย่างไร / lat, lon (หรือ "ไม่พบ") / แหล่งอ้างอิง
อย่างน้อยหนึ่งแห่งต่อทุกยุคของเรื่อง สถานที่ที่ไม่มีใน OpenStreetMap คือสิ่งที่ต้องการมากที่สุด
โดยเฉพาะ: **แนวกำแพงหรือคูเมืองพิชัยและจุดที่รบ** **ท่าเรือท่าอิฐ** **บ่อเหล็กน้ำพี้**

## ข้อกำหนด

- ให้ความสำคัญกับแหล่งภาษาไทย เช่น กรมศิลปากร ศิลปวัฒนธรรม ThaiJO เว็บจังหวัดและเทศบาลเมืองอุตรดิตถ์
  มหาวิทยาลัยราชภัฏอุตรดิตถ์ วิกิพีเดียภาษาอังกฤษมักผิดเรื่องปีของประวัติศาสตร์ท้องถิ่นไทย
- ทุกปีที่ระบุต้องมีลิงก์หรือชื่อเอกสารอ้างอิง
- ถ้าหาไม่เจอ ให้เขียนว่า "ไม่พบ" แทนการเดา
- แยกให้ชัดว่าเรื่องไหนเป็นตำนาน เรื่องไหนเป็นพงศาวดาร และเรื่องไหนเป็นหลักฐานร่วมสมัย
