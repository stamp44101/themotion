# เริ่มต้นใช้งาน 1minutecity Skill

ขอบคุณที่ซื้อครับ ไฟล์นี้พาคุณจากศูนย์จนได้คลิปแรก ใช้เวลาติดตั้งราว 20–30 นาที

## 1. ติดตั้งเครื่องมือ (ครั้งเดียว)

| เครื่องมือ | ใช้ทำอะไร | ดาวน์โหลด |
|---|---|---|
| **Node.js 20 หรือ 22** (LTS) | รันเอนจินและเรนเดอร์วิดีโอ | nodejs.org |
| **Python 3.10+** | สังเคราะห์ดนตรีและเสียงเอฟเฟกต์ | python.org |
| **ffmpeg** | ทำไฟล์อัปโหลดและ contact sheet | ffmpeg.org (Mac: `brew install ffmpeg`) |
| **Claude Code** | AI ที่เขียนโค้ดตาม skill ให้คุณ ต้องมีแพ็กเกจ Claude แบบเสียเงิน | claude.com/claude-code |

ถ้ามีการ์ดจอ (NVIDIA, AMD หรือ Mac รุ่น M) จะเรนเดอร์คลิป 60 วินาทีได้ในราว 1–2 นาที ไม่มีก็ใช้ได้ แต่ราว 35–50 นาทีต่อคลิป

## 2. เปิดโปรเจกต์

1. แตกไฟล์ zip ไว้ในโฟลเดอร์ที่ไม่มีช่องว่างหรือภาษาไทยในชื่อ เช่น `C:\work\1minutecity` หรือ `~/work/1minutecity`
2. เปิด terminal ในโฟลเดอร์นั้น แล้วพิมพ์ทีละบรรทัด:

```bash
npm install
pip install numpy scipy
npm run check
```

ถ้า `npm run check` จบโดยไม่มีข้อความ ERROR แปลว่าพร้อมแล้ว (มี WARN ได้ ไม่เป็นไร)

## 3. ดูคลิปตัวอย่างโคราช

```bash
npm run studio
```

เบราว์เซอร์จะเปิดหน้า Remotion Studio เลือก **Korat** ทางซ้าย แล้วกดเล่น นี่คือคลิปที่ได้ 131K วิวบน Instagram ทุกอย่างในนั้นอยู่ใน `src/cities/korat/`

เรนเดอร์เป็นไฟล์จริง:

```bash
npm run render:korat
npm run encode -- korat
```

ได้ `out/korat_social.mp4` ไฟล์เดียวลงได้ทั้ง TikTok, Instagram และ Facebook

## 4. ทำเมืองของคุณ

พิมพ์ `claude` ใน terminal ที่โฟลเดอร์โปรเจกต์ แล้วสั่งเป็นภาษาไทยได้เลย เช่น

> ทำคลิปประวัติเมืองเชียงใหม่ตาม skill thai-city-timelapse เริ่มจากบรีฟและเช็กวันที่ก่อน แล้วทำ style frame 3 แบบให้ผมเลือก

Claude จะทำตามขั้นตอนใน skill: บรีฟ → style frame → วางผังจากพิกัดจริง → จังหวะเรื่อง → ภาพนิ่ง → เสียง → ตรวจ → เรนเดอร์ หน้าที่ของคุณคือดูภาพนิ่งที่ Claude ทำมาแล้วบอกว่าตรงไหนไม่ใช่

**เคล็ดลับจากการทำจริง**
- ให้ Claude ทำ contact sheet (ภาพนิ่ง 8–12 ภาพเรียงกัน) ทุกครั้งก่อนเรนเดอร์เต็ม แก้บนภาพนิ่งเร็วกว่ามาก
- 3 วินาทีแรกต้องมีของใหญ่ที่ขยับ คนตัดสินใจเลื่อนผ่านใน 3 วินาที
- ตรวจวันที่และข้อเท็จจริงเองอีกรอบก่อนโพสต์ คลิปประวัติศาสตร์มีคนในพื้นที่ดูและทักเสมอ
- โพสต์จากเว็บ ไม่ใช่จากแอปมือถือ แอปจะบีบไฟล์ก่อนอัปโหลด

## 5. อัปเดต
