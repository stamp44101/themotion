# เงื่อนไขการใช้งาน 1minutecity Skill

**ทำได้**
- ใช้ skill และเอนจินนี้ทำคลิปได้ไม่จำกัดจำนวน
- คลิปที่คุณทำเป็นของคุณ ลงช่องตัวเอง เปิดสร้างรายได้ หรือรับทำให้ลูกค้าได้ ไม่ต้องให้เครดิต (ถ้าแท็ก @1minute.city เราจะดีใจมาก)
- แก้ไขโค้ดได้ตามต้องการเพื่อใช้ในงานของคุณ

**ทำไม่ได้**
- ขายต่อ แจก หรือเผยแพร่ไฟล์ skill เอนจิน หรือสคริปต์ ไม่ว่าจะแก้ไขแล้วหรือไม่
- นำคลิปที่เพจ 1minutecity โพสต์ หรือคลิปโคราชตัวอย่างที่เรนเดอร์ออกมาโดยไม่แก้ ไปโพสต์ซ้ำ

**ความรับผิดชอบ**
- ข้อมูลประวัติศาสตร์ในคลิปของคุณ คุณต้องตรวจสอบเองก่อนเผยแพร่
- ระบบนี้สร้างบน **Remotion** (remotion.dev) ซึ่งใช้ฟรีได้สำหรับบุคคลและบริษัทขนาดเล็ก องค์กรที่มีพนักงานเกินเกณฑ์ของ Remotion ต้องซื้อใบอนุญาตของ Remotion เอง ตรวจเงื่อนไขล่าสุดที่ remotion.dev/license
